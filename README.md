# FE-ProjectKTPM-ShopShoes

## Giới thiệu
FE-ProjectKTPM-ShopShoes là dự án Frontend cho website bán giày dép, được phát triển nhằm mang đến trải nghiệm mua sắm trực tuyến hiện đại, thân thiện và tiện lợi cho người dùng. Ứng dụng cho phép khách hàng dễ dàng tìm kiếm, xem chi tiết sản phẩm, đặt hàng, thanh toán và quản lý tài khoản cá nhân.

## Liên kết liên quan
- [Backend Project ShopShoes(BE-ProjectKTPM-ShopShoes_N13)](https://github.com/leminh2110/BE-ProjectKTPM-ShopShoes-N13.git)
- [Frontend Project ShopShoes(FE-ProjectKTPM-ShopShoes_N13)](https://github.com/leminh2110/FE-ProjectKTPM-ShopShoes-N13.git)

## Tính năng chính
- Đăng ký, đăng nhập và xác thực người dùng
- Duyệt, tìm kiếm và lọc sản phẩm giày dép
- Xem chi tiết sản phẩm, hình ảnh, mô tả, giá bán
- Thêm sản phẩm vào giỏ hàng và đặt hàng trực tuyến
- Quản lý đơn hàng, theo dõi trạng thái giao hàng
- Quản lý thông tin cá nhân và đổi mật khẩu
- Nhận thông báo về đơn hàng và khuyến mãi

## Công nghệ sử dụng
- ReactJS (hoặc VueJS/Angular, tùy công nghệ bạn dùng)
- Redux (hoặc Context API)
- RESTful API để giao tiếp với backend
- Axios hoặc Fetch API để gọi dữ liệu
- Các thư viện UI như Ant Design, Material UI, Bootstrap (nếu có)
- Webpack, Babel, ESLint, v.v.

## Hướng dẫn cài đặt & chạy thử
1. Clone repository về máy
2. Cài đặt dependencies: `npm install` hoặc `yarn install`
3. Chạy ứng dụng: `npm start` hoặc `yarn start`
4. Truy cập website tại địa chỉ được cung cấp trên terminal
